## 2. Scope Basis

- Platform: responsive web SPA in TypeScript with static hosting over HTTPS (ASM-1). Not confirmed against OQ-001; if changed, only UI-layer, `LocationService` and `KeyValueStore` tasks (TASK-020, TASK-021, TASK-026 to TASK-035) are re-planned.
- Architecture: ports and adapters. Core (C2 to C12) has no browser or provider code.
- Toolchain choices beyond TypeScript and React (bundler, test runner, linter, CSS approach) are **not specified** by the architecture. The Implementer proposes them in TASK-003, and they are recorded in the task result for user visibility.
- Out of scope (per architecture Section 2 and ODD-14): accounts/sync, alerts, hourly forecast, more than 3 days, background refresh, maps, extra languages, offline mode, extra metrics, favorite reordering, analytics/logging. No task here covers them.
- No keyed provider and no proxy (architecture 6.2) is planned. If the user selects a keyed provider, the architecture must be revised and re-reviewed first, and tasks TASK-022, TASK-023 and TASK-024 are replaced.
